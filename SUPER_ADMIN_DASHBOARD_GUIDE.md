# Super Admin Dashboard – User Operating Guide

## 1. Introduction to Super Admin Control

The **Super Admin Control** workspace is the highest-level management portal in the Case Management Website. It provides complete oversight over firm-wide performance, administrative user access, active case velocity, quality control reviews, system security logs, and financial transactions.

---

## 3. Detailed Menu & Button Directory for Super Admin

### 1. Dashboard (`Dashboard` Tab)
* **Purpose**: Overview of all firm operations and high-level activity.
* **What you see**: Active case cards, total clients counter, pending review count, active task count, and real-time activity log feed.
* **Buttons & Their Actions**:
  * **✨ Babel AI Petition Drafter** (Top Header/Sidebar) ➔ Opens the **AI Assistant Modal** to run AI legal analysis, summarize evidence, or generate template drafts.
  * **🔔 Notifications Bell** (Top Header Right) ➔ Opens the **Notifications Panel** showing recent system-wide updates.
  * **👤 Role Switcher Dropdown** (Top Header Right) ➔ Allows switching role view to Admin, Writer, Reviewer, or Client for demonstration.
  * **➕ Create New Case Button** ➔ Opens **New Case Creation Modal** to initialize a case across the firm.
  * **➕ Add New Client Button** ➔ Opens **New Client Onboarding Modal** to register a new client profile.

---

### 2. Admin Management (`Admin Management` Tab)
* **Purpose**: Managing administrative staff accounts and auditing security activity logs.
* **What you see**:
  * **System Users Table**: List of all Administrators, Drafters, and QA Reviewers, their email addresses, assigned roles, and status.
  * **Audit Log Entries**: Timestamped log of every action taken in the system (case creation, stage changes, document uploads, role modifications).
* **Buttons & Their Actions**:
  * **➕ Add New Admin / User Button** ➔ Opens user registration modal to create new Admin, Writer, or Reviewer accounts.
  * **✏️ Edit Role / Permissions Button** (Next to user row) ➔ Opens permission editor to adjust user access rights.
  * **🔒 Deactivate User Button** (Next to user row) ➔ Temporarily suspends user access to the platform.
  * **🔍 Search Activity Logs** ➔ Filters system audit logs by user email or action keyword.

---

### 3. All Cases (`All Cases` Tab)
* **Purpose**: Master view of every active, pending, or completed case across the entire firm.
* **What you see**: Table and card grid of all cases showing Case Number, Client Name, Petition Category (EB-2 NIW, EB-1A, O-1), Current Stage (1 to 14), Assigned Writer & Reviewer, and Risk Level.
* **Buttons & Their Actions**:
  * **➕ Create New Case Button** ➔ Opens the **New Case Creation Modal**.
  * **🔍 Case Search Bar** ➔ Live search by client name, case number, or field category.
  * **🏷️ Filter by Petition Category Dropdown** ➔ Filters cases by *EB-2 NIW*, *EB-1A*, *O-1*, *Resume Building*, etc.
  * **🚦 Filter by Risk Level Dropdown** ➔ Filters cases by *High Risk*, *Medium Risk*, or *Low Risk*.
  * **👁️ View Case Details / Open Case Button** (On case card/row) ➔ Opens full Case Detail view showing Dhanasar prongs, recommenders, tasks, and document exhibits.

---

### 4. Clients (`Clients` Tab)
* **Purpose**: Comprehensive database of all registered clients and petitioners.
* **What you see**: List of clients with their name, email, phone number, field of expertise, highest degree, publication count, and status (*Active*, *On Hold*, *Approved*, *Archived*).
* **Buttons & Their Actions**:
  * **➕ Add New Client Button** ➔ Opens **New Client Form** to register a new client.
  * **👁️ View Profile Button** ➔ Opens client profile summary including linked cases and uploaded credentials.
  * **✏️ Edit Client Button** ➔ Opens client details modal to update contact info, field of expertise, or degree credentials.

---

### 5. Reviews & Approvals (`Reviews & Approvals` Tab)
* **Purpose**: Oversight of quality control signoffs and petition reviews.
* **What you see**: Queue of submitted recommendation letters and petition memorandums awaiting senior review.
* **Buttons & Their Actions**:
  * **👁️ Review Submission Button** ➔ Opens legal review modal to read petition drafts and reviewer notes.
  * **✅ Approve Signoff Button** ➔ Grants final legal approval for petition package assembly.
  * **🔄 Request Revision Button** ➔ Sends petition draft back to Drafter with specific comments.

---

### 6. Communication (`Communication` Tab)
* **Purpose**: Firm-wide message management and WhatsApp live chat.
* **What you see**: Active message threads per case, communication history, and live chat logs.
* **Buttons & Their Actions**:
  * **💬 Messaging Hub Logs Button** (Sidebar sub-menu) ➔ Displays full message logs between clients and legal teams.
  * **📱 WhatsApp Live Chat Button** (Sidebar sub-menu) ➔ Opens the **WhatsApp Live Chat Modal** for instant direct messaging.
  * **✉️ Send Message Button** ➔ Sends in-app notification and message to selected client or team member.

---

### 7. Payments (`Payments` Tab)
* **Purpose**: Overview of firm revenue, billing milestones, and payment processing.
* **What you see**: Financial summary metrics (Total Revenue, Paid Amount, Pending Invoices, Overdue Payments) and invoice table.
* **Buttons & Their Actions**:
  * **💳 Record Payment Button** ➔ Opens payment entry modal to log received payments.
  * **📥 Download Receipt Button** (On invoice row) ➔ Downloads official payment receipt as PDF.
  * **🏷️ Filter Payment Status Dropdown** ➔ Filters list by *Paid*, *Pending*, or *Overdue*.

---

### 8. Reports & Settings (`Reports` & `Settings` Tabs)
* **Purpose**: Performance analytics and global firm settings.
* **What you see**: Case velocity charts, stage distribution metrics, approval rates, global petition templates, and firm profile settings.
* **Buttons & Their Actions**:
  * **📊 Export Report Button** ➔ Downloads firm performance report as spreadsheet/PDF.
  * **⚙️ Save System Settings Button** ➔ Saves global firm name, logo, default service centers, and notification rules.
